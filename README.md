# Australian Bookkeeping Portfolio Website

A responsive, one-page portfolio template for an aspiring bookkeeper targeting Australian small businesses. Built with plain HTML, CSS, and JavaScript—no paid tools or build process required.

## Files
- `index.html` — website content
- `styles.css` — layout, colours, typography, and responsive styling
- `script.js` — mobile navigation toggle

## Personalise before publishing
1. Open `index.html` in a text editor.
2. Replace `YOUR NAME` with your preferred professional name.
3. Replace `your.email@example.com` with an email address you want employers to use.
4. Replace the LinkedIn link (`https://www.linkedin.com/`) with your profile URL.
5. Update the About and Skills sections as you complete training and certifications.
6. Add links to real project files only when the work is ready to share. Keep all sample data fictional and clearly labelled.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Click **New repository**. Name it `yourusername.github.io` (replace `yourusername` with your GitHub username).
3. Choose **Public**, then create the repository.
4. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository's root. You can use **Add file → Upload files** on GitHub.
5. Open **Settings → Pages**.
6. Under the build/deployment source, choose **Deploy from a branch**; select `main` and `/ (root)`, then save.
7. Wait for the deployment to finish. Your site should be available at `https://yourusername.github.io/`.

GitHub's interface may change, so consult the official documentation if the labels differ:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Portfolio honesty checklist
- Label all practice projects as fictional or sample work.
- Do not claim paid client experience you do not have.
- List software certifications only after you earn them.
- Avoid publishing personal home addresses, identity documents, or sensitive client information.
- Use only figures and business records you created or have permission to share.
